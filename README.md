# Haika — Integrated Interior-Design Lead System Demo

## Purpose

Create a sales-ready demo for Haika that shows how an interior-design studio can capture, qualify, follow up with, and manage new leads in one connected experience.

The demo represents a bundled offer:

1. A modern, conversion-focused marketing website.
2. A conversational chatbot for initial lead capture and qualification.
3. Follow-up automation that routes leads and keeps prospects moving.
4. An internal dashboard for visibility and action.

## Demo Story

A homeowner arrives from a marketing campaign, explores relevant work, and starts an enquiry. The chatbot or enquiry form collects project type, location, property size, budget range, timeline, and contact details. The system assigns a lead status, notifies the sales/design team, and creates a clear next action. The dashboard makes the pipeline and follow-up state visible at a glance.

## Target User Roles

| Role | Primary need |
| --- | --- |
| Prospective homeowner | Quickly see fit, understand the service, and request a consultation. |
| Sales/design coordinator | Receive qualified leads, prioritize them, and follow up reliably. |
| Studio owner | See pipeline health, sources, conversion signals, and outstanding work. |

## Core Demo Scope

- **Public website:** landing page, services, selected portfolio, social proof, consultation CTA, and enquiry flow.
- **Chatbot:** guided qualification with concise, human-sounding questions; an optional handoff to a person.
- **Automation:** lead normalization, routing, acknowledgement, internal notification, follow-up tasks, and status updates.
- **Dashboard:** lead list, lead detail, pipeline statuses, follow-up queue, source summary, and simple performance metrics.

## Boundaries for the First Demo

- Use realistic demo data only; do not connect real WhatsApp, email, CRM, payments, or calendars yet.
- Keep authentication, permissions, integrations, analytics, and data retention as design considerations—not production commitments.
- Design the system so external services can be connected later without changing the user journey.

## Success Criteria

The demo should let a viewer complete this end-to-end story without explanation: discover the studio, submit or chat through an enquiry, see the lead appear in the dashboard, and understand the automated next step.
